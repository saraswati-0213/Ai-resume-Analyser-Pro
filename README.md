## 💡 **How It Works**
1. **Upload or Start from Scratch:** Import your resume in **PDF/Word** or create one with our AI builder.
2. **Analyze Your Resume:** Get instant ATS score metrics, keyword insight loops, and core structural gap maps.
3. **Build & Refine:** Polish data points dynamically with 4 premium automated layouts.
4. **Download & Apply:** Export clean recruiter-ready PDF formats natively.

## 🛠️ **Setup Instructions**

Follow these steps to deploy **AI-Resume-Analyzer-Pro** on your local machine:

1. **Navigate to the repository folder:**
   ```bash
   cd AI-Resume-Analyzer-Pro
2. Set up a Virtual Environment (Optional):

      Bash
      python -m venv venv
      Windows: venv\Scripts\activate

      Mac/Linux: source venv/bin/activate

3. Install dependencies:

      Bash
      pip install -r requirements.txt
      Download the spaCy model:

      Bash
      python -m spacy download en_core_web_sm
      Configure Environment Variables (Mandatory):

      Create a .env file inside the utils/ directory.

      Add your Google Gemini API Key:

Code snippet
GOOGLE_API_KEY=your_google_gemini_api_key
🔑 Get your key from Google AI Studio.

Run the application:

Bash
streamlit run app.py

Username: admin@example.com

Note: The Admin Section will be visible only after a successful login step right below the primary panels.

🚨 Known Bug: Autofill Glitch
If you're using browser Autofill for text fields, you might see a structural alert block.

Quick Fix: Delete the last character of the input box manually and type it back. This forces the Streamlit state tree to catch the changes smoothly.
